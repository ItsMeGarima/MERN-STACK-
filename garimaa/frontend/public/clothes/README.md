# Product Images

Is folder me asli kapdon ki photos daalni hain.

## Unsplash se download karne ka tarika:

1. https://unsplash.com par jao
2. Search karo:
   - "men clothing" / "men fashion"
   - "women clothing" / "women fashion"
   - "kids clothing"
   - "ethnic wear" / "traditional clothing"
   - "winter wear" / "jacket"

3. Kisi bhi photo par click karo
4. "Download free" button par click karo (600x600 ya 1000x1000 size)
5. Downloaded photo ko is folder me save karo
